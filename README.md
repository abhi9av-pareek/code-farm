# Abhinav's Code Farm 🌱

A 3D developer portfolio built with React + TypeScript + React Three Fiber + Three.js + Tailwind CSS.

## First run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## What to learn in Milestone 1

- React components can represent parts of a 3D scene.
- React Three Fiber turns Three.js objects into JSX such as `<mesh />`, `<boxGeometry />`, and `<meshStandardMaterial />`.
- `useFrame()` gives a component access to the render loop, which we use for the windmill animation.
- Drei provides higher-level helpers such as `Sky` and `OrbitControls`.
- Tailwind CSS v4 can be integrated with Vite using `@tailwindcss/vite`.
